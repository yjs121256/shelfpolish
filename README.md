# ShelfPolish

Public site for ShelfPolish, a fixed-price Shopify product listing cleanup service from Yunju Company (Gwangju, South Korea).

Contact: yjs121256@gmail.com

Site files are in this repository (`index.html`, `terms.html`, `order-brief.txt`). To publish them on GitHub Pages (free):

1. Open https://github.com/yjs121256/shelfpolish/settings/pages
2. Under "Build and deployment", set Source to "Deploy from a branch"
3. Set Branch to `main` and the folder to `/ (root)`, then Save

The site will be at https://yjs121256.github.io/shelfpolish/
